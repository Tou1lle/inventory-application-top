# 🧩Inventory Application
This project is a Inventory/Database for an imaginary Gaming list. This game includes Publishers, Developers and 
their respective games. All the data are not guaranteed, they are added manually via forms by users.
The Odin Project instructions for this project can be found [here](https://www.theodinproject.com/lessons/node-path-nodejs-inventory-application).

## Database

For this project I created a database schema in [dbdiagram](https://dbdiagram.io/home), which uses a special 
but similar syntax to SQL DBML.
